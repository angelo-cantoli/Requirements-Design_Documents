\subsection{Used Tools}
The following tools have been used to create this document:
\begin{itemize}
    \item \textbf{LaTeX}: for document preparation and typesetting.
    \item \textbf{PlantUML}: for creating UML sequence diagrams included in the document.
    \item \textbf{GitHub}: for version control and collaboration on the document source files.
    \item \textbf{Figma}: for designing user interfaces and prototyping.
    \item \textbf{VSCode}: as the main text editor for writing LaTeX code.
    \item \textbf{StarUML}: for creating the component and deployment diagrams included in the document.
\end{itemize}

\subsection{Use of Generative AI}
For the development of the mockups used in the 'User Interface Design' section, \textbf{Uizard} was used.
This is a generative AI tool that assists in quickly creating user interfaces. We felt this tool was appropriate 
for the scope of the project, as it simply aided in creating a visual aid for the document, and did not contribute 
in any way to the textual content and descriptions of the 'User Interface Design' section.
